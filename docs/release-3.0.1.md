# Sentra SOC 3.0.1

2026-10-23 维护版本，包含大库备份、恢复演练、队列恢复与展示一致性改进。

## 升级

1. 先保存配置、密钥和经过验证的数据库备份；不要将它们上传 GitHub。
2. 在隔离环境安装并验证 `pip install 'monitor3[backup-verify]'` 对应的本版 wheel。
   从源码安装使用 `pip install '.[backup-verify]'`。
3. 检查新依赖下限：Paramiko 5.1、cryptography 50.0.2、urllib3 2.8、
   Werkzeug 3.1.9 和 certifi 2026.10.19。SSH 对端必须支持现代签名算法；
   不建议为了兼容老设备重新启用 SHA-1。
4. 停止应用服务后安装本版 wheel，保留自己的配置和日志挂载，重新启动并核对心跳。
5. 在隔离数据库运行恢复演练；绝不能用生产数据库作为演练目标。

只读压缩校验器需要显式设置 `MONITOR_BACKUP_VERIFY_BACKEND=compressed`。
它仅改变验证时的读取方式，发布的备份仍为普通 SQLite 文件。
完整检查和 quick_check 不等价；本版不会把超时或校验失败当作成功。
常规发布前检查会读取数据库，大库应预留检查时间，不要在高峰期重复全量扫描。

## 验证范围

全量自动化测试包含数据库锁冲突、七天事件保留、受限网段任务、任务租约、VPN 审计关联、
大屏趋势、备份损坏/超时拒绝及隔离恢复。另有前端请求超时、图形渲染和 VPN 展示检查。
本地通过不等于所有设备型号或 GitHub CI 平台已验收。

## 已知限制

- VPN 公网 IP 必须由设备登录审计或可信会话来源上报；内网 IP 和第三方归属地查询不能反推公网 IP。
- 未开启或未提供真实日志的数据源不会生成模拟事件；演示空态不等于采集故障。
- 静态检查的已复核告警和依赖审计范围见 [安全复核](security-review-3.0.1.md)。
- 备份、通知及自动处置开关保留现有环境设置，不因升级而自动启用。
