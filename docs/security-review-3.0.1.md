# 3.0.1 发布安全复核

依赖审计发现旧环境存在已知漏洞依赖，本版提高修复版下限并在全新环境重新审计。
不将旧环境审计结果与新版安装环境混为一谈；漏洞数据库会变化，部署后仍需持续审计。
CI 从安装元数据枚举全部第三方依赖的精确版本，仅排除非 PyPI 本地应用 monitor3，
对完整清单执行严格审计。所有第三方运行依赖、可选备份依赖和审计工具依赖仍被覆盖，
并拒绝缺失或冲突的版本元数据；应用源码由静态检查覆盖。

Bandit 静态告警需人工解释，不能称为实际漏洞数量或安全保证。本版保留现有严格扫描流程，
对以下已复核位置逐条添加带理由的特定规则注解，未全局跳过规则或降低流水线门槛。
新增代码仍接受完整扫描；修改相关语句时必须重新审查注解是否仍然成立：

- SQL 拼接主要为参数占位符、固定列名及固定筛选子句，值另行绑定；后续改动仍须逐处审查。
  网段任务更新列名和清理目标另增加显式允许列表，非法标识符在执行 SQL 前拒绝。
- 空字符串默认令牌表示未配置，不是可登录的固定凭据；命令 create/revoke 不是密码。
- 校验子进程使用参数数组且不经 shell，并有超时；备份镜像仅接受独立快照。
- 解析和归属地查询异常允许降级，不代表数据校验可跳过。

自动化测试及静态分析不是渗透测试。不要公开上传生产数据库、日志、设备清单或访问令牌。
