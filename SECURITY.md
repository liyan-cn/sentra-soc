# Security Policy

Do not open public issues for vulnerabilities or include credentials, internal
addresses, production logs, database files, or exploit details in reports.

Please send a private report to the security contact configured by the project
maintainer. Include affected versions, impact, reproduction steps, and a safe
proof of concept. Maintainers should acknowledge reports within 7 days and
publish coordinated fixes and advisories after remediation.

This is an evolving project; no formal support lifetime or response SLA is guaranteed.
Firewall execution is disabled by default. Users must rotate any credential that
may have appeared in logs or an earlier release.
